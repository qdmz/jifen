## 1. 两个入口、三种角色

| 入口 | 地址 | 谁能进 |
| --- | --- | --- |
| 村民端 | `https://你的域名/jifen.html` | 所有人，不用登录 |
| 管理后台 | `https://你的域名/jifen-admin.html` | 账号密码登录 |

后台角色：

| 角色 | 权限 | 给谁 |
| --- | --- | --- |
| `admin` 管理员 | 全部功能，含备份恢复、改密码 | 村支书 / 积分超市负责人 |
| `editor` 编辑员 | 记分、核销、账户、商品、规则，不能备份恢复 | 值班干部、网格员 |
| `viewer` 浏览员 | 只能看，所有修改按钮都隐藏 | 监委会、上级检查 |

> 新建账号：目前没有账号管理界面，用命令行在服务器执行
> `python tools/reset_pwd.py --user 张三 --pwd 初始密码`（会建成 admin 角色）。
> 忘记密码同样用它重置。

## 2. 村民端

### 2.1 怎么查积分

点「查积分」，输入**姓名**，再加下面任意一种凭证：

| 凭证 | 适用 | 说明 |
| --- | --- | --- |
| 手机号 | 登记过手机的家庭 | 最常用 |
| 身份证后 6 位 | 没手机号但登记了身份证 | 身份证尾号可能是 X，大小写都行 |
| 6 位积分码 | 什么信息都没登记的老人 | 后台账户列表能查到，可打印成卡片发给本人 |

- **同名怎么办**：系统会返回同名的几个人，让你选村民组；选对了才进得去。
- **防刷**：连续输错 6 次会锁 5 分钟，属正常保护。
- 查到的页面可以一直开着，30 分钟内可继续兑换；超时再查一次即可。

### 2.2 怎么兑换

1. 查分后进入「我的积分」，下方就是商品列表
2. 选分类（食品粮油 / 生活用品 / 学习用品 …）
3. 点「兑换」，确认扣分和库存
4. 成功后得到 **6 位取货码**，同时进入「我的兑换 → 待领取」

到积分超市（村委会）把取货码报给值班人员，对方在后台输入核销，状态变「已领取」。

> 兑换后会立即扣分、扣库存。若商品缺货，工作人员可「取消订单」，积分和库存会自动退回。

### 2.3 我的兑换

| 状态 | 含义 |
| --- | --- |
| 待领取 | 已扣分，等你去超市拿东西 |
| 已领取 | 已核销完成 |
| 已取消 | 工作人员取消，积分已退回 |

超过 7 天未领取，后台会提醒，村里可决定是否取消退分。

### 2.4 积分榜与红黑榜

- **积分榜**：个人榜、户榜（按户合计）。对外展示会隐藏姓名中间字，保护隐私。
- **红黑榜**：红榜是好人好事（义务劳动、孝老爱亲、调解纠纷…），黑榜是不文明行为（违规办酒、乱倒垃圾…），可配图片。
- **积分规则**：所有加减分事项和分值都公开，村民可随时核对「为什么他家分高」。

## 3. 管理后台

登录后左侧是模块菜单，右上角可以「改密码」「退出」。

### 3.1 数据概览

一屏看全：账户数、累计发放、累计兑换、核销率、待领取笔数、库存预警（≤5 件）、最近兑换。**每天早上瞄一眼**，有「待领取超 7 天」就去催一下。

### 3.2 数据大屏

选日期区间（7/30/90 天），看：

- 每日加分/兑换趋势
- 加分事由 Top（哪个活动最来分）
- 各村民组参与度对比
- 个人榜/户榜切换

适合开会投屏、月度公示。

### 3.3 商品管理

- 新增商品：名称、分类、图标（emoji 就行）、规格、所需积分、库存、每人限兑、上架状态、排序
- 「下架」不会影响已兑换的订单
- 库存为 0 时村民端会显示「已兑完」，无法下单

> 建议：单价定在 10~150 分，常备米面油、洗衣粉、文具，库存按季度补。

### 3.4 积分发放（最常用）

1. 选人：可按姓名/手机/组别搜，也可点组名 chip **一键全选该组**
2. 填分值（可正可负，负数是扣分）
3. 填事由：从规则里选，或自己写
4. 确认发放 → 生成一条 `earn` 流水，余额立刻增加

批量发放 200 人也只需一次提交。**发放记录会在「积分流水」里留痕（含操作人）**。

### 3.5 兑换核销

1. 让村民报 6 位取货码
2. 输入 → 显示订单明细（谁、换了什么、多少分）
3. 点「核销」→ 状态变「已领取」

特殊情况：

| 情况 | 操作 |
| --- | --- |
| 商品缺货 / 村民改主意 | 「取消订单」→ 自动退分、回补库存 |
| 码输错 | 会提示「未找到该取货码」，让村民在手机上再看一次 |

### 3.6 积分账户

顶部两个视图：

- **按人**：一览每个人的组别、所属户、电话、积分码、余额、累计。行内可「分户 / 编辑 / 加减分 / 删除」。
- **按户**：按「组·户主」聚合，看户积分、在册人数、有积分人数；点「查看成员」看本户明细和流水。

常用操作：

| 操作 | 位置 | 说明 |
| --- | --- | --- |
| 从户籍导入 | 按人视图右上 | 按户籍台账批量建账户（有同名同手机号会跳过） |
| 补齐积分码 | 按人视图右上 | 给没手机号、没积分码的人批量生成 6 位码 |
| 导出登录卡 | 按人视图右上 | 生成 CSV/卡片，打印发给老人 |
| 分户调整 | 按人视图右上 / 行内「分户」 | **人工指定哪些人属于同一户**，详见下 |
| 分户核对 | 按户视图右上 | 列出「待核」（同址多户）和「单户口」，逐个核对 |

**分户调整怎么用**

系统默认按「家庭成员健康信息表 → 手机号 → 户籍地址」自动归户，难免有错（兄弟同栋、附 1 号、上门女婿等）。发现错了：

1. 点「分户调整」（或在某人行内点「分户」，会自动勾上他）
2. 左栏搜索并勾选要调整的人（可多选，同名看组别电话）
3. 右栏选一种方式：
   - **并入已有户**：搜户主名选中目标户
   - **新建一户**：填户主姓名 + 村民组（该组已有同名户会直接并入）
   - **移出本户**：先退出来，暂不归户，之后再并到正确户
   - **恢复自动**：撤销人工指定，交还给自动判断
4. 确认 → 提示「已把 N 人归入「某某」户」

人工调整过的账户会打上「人工」标记，**以后资料同步、自动重算都不会覆盖你的修改**。整户调错也能救：进「按户」→「查看成员」→「调整本户成员」，整户一起挪到正确的户。

### 3.7 积分流水

按姓名/事由/时间筛选，每条记录包含：时间、姓名、事由、变动分值、变动后余额、操作人、来源（后台/村民自助/退款）。

- 导出 CSV 用于公示或报账
- 余额是「逐笔顺推」的，可以用来对账

### 3.8 积分规则

维护加减分事项：名称、分类、分值、单位（次/月/户）、说明、启用状态、排序。
建议控制在 20 条以内，用大白话写，村民一看就懂。

### 3.9 红黑榜

- 发布案例：选红榜/黑榜、标题、姓名/户主、组别、分值、经过、图片、发生日期
- 村民端按排序展示；「下架」后立即不显示
- 黑榜姓名可按设置隐藏中间字

### 3.10 数据管理

| 功能 | 说明 |
| --- | --- |
| 立即备份 | 生成 JSON 存到 `data/backups/jf/`，保留最近 20 份，可下载 |
| 从文件恢复 | 上传备份 JSON 恢复；恢复前自动存一份，可反悔 |
| 导出 CSV | 账户、流水、兑换单、户表 |
| 健康体检 | 检查无码账户、无手机号、待核分户、图片缺失、超期未领取等 |

**建议每周做一次「立即备份」并下载到电脑**，尤其在做批量导入/恢复之前。

### 3.11 超市设置

超市名称、标语、公告、兑换须知、开放时间、黑榜是否脱敏、榜单是否显示户榜等。

## 4. 一个月怎么跑（积分制落地流程）

| 时间 | 做什么 |
| --- | --- |
| 月初 | 「积分规则」确认本月加减分事项；「商品管理」补货上架 |
| 日常 | 活动结束当天就把分记上（「积分发放」，按组全选很快）；兑换随时核销 |
| 每周 | 「数据管理 → 立即备份」下载一份；看「数据概览」有无超期未领取 |
| 月末 | 「数据大屏」截图 → 公示；「积分流水」导出 → 存档；核对户榜 |
| 季度 | 「分户核对」过一遍待核和单户口；清理长期不参与的账户（停用而非删除） |
| 年底 | 积分榜排名 → 评星、评优；红黑榜整理归档；备份全量导出 |

小技巧：

- 记分尽量**当天记**，事由写具体（「8月环境整治」比「义务劳动」好查）
- 一次活动一批人：用组别 chip 全选，避免漏人
- 老人没手机：打印「登录卡」（姓名 + 6 位积分码），让家人或网格员代查

## 5. 常见问题

**Q：村民说查不到自己的积分？**
A：先看账户列表有没有他。没有就「从户籍导入」或「+ 新增账户」。有则核对姓名是否完全一致（别多空格）、组别是否选对；没手机号的给他 6 位积分码。

**Q：同名同姓怎么区分？**
A：查分时会让他选村民组；若同组还同名，后台把其中一人的组别或姓名做区分（如「王强（大）」），或改用积分码登录。

**Q：兑换扣了分但东西没拿到？**
A：后台「兑换核销」查取货码，核销即可；确实不给了就「取消订单」，积分自动退回。

**Q：户积分不对（把两家人算一户了）？**
A：「积分账户 → 分户调整」，把不是这户的人勾出来，「移出本户」或「并入」正确户。整户错就进「按户 → 查看成员 → 调整本户成员」。

**Q：能改历史流水吗？**
A：不能直接改。记错了就补一笔反向调整（如 -10 分，事由写「更正 8/12 误加」），保留痕迹更规范。

**Q：账户能删吗？**
A：有兑换记录的账户不能删，只能「停用」。停用后不能登录查分，历史流水仍在。

**Q：想让村民只看到榜单、不显示真实姓名？**
A：「超市设置」里开启姓名脱敏；户榜只显示「某户」，个人榜隐藏中间字。

**Q：能同时开两个入口吗（村居系统里一个、独立域名一个）？**
A：可以，但必须共用同一个数据库（见 DEPLOY.md 第 7 节「共享库」），否则两边积分会对不上。
