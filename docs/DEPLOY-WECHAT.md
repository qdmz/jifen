# 部署到微信小程序 / 公众号

> 目标：把积分超市装进微信——村民在微信里打开小程序查积分、兑换，公众号菜单也能一键进入。
> 本机代码部分已完成（`miniprogram/` + 后端接口复用），剩下的是**微信后台的账号配置**，这部分必须由账号管理员在网页上操作。

---

## 当前方案（2026-11-10 起）：小程序走云服务，不再需要备案域名

小程序的数据已经迁到 **WorkBuddy 云服务**（云数据库 + 云函数），请求打的是平台域名
`https://mp-api.app.workbuddy.host`，**不再回源到本机自建服务**。直接影响：

| 原来的卡点 | 云服务版 |
|---|---|
| 需要 ICP 备案域名才能配 request 合法域名 | 不需要自己备案，平台域名已备案 |
| 需要公网隧道 / CDN 回源 | 不需要，去掉 `start_tunnel.bat` 也能跑 |
| 后端要一直开着 | 不需要，关掉 `app.py` 小程序照常工作 |
| 改接口地址要改 `apiBase` | 改成云环境配置（`utils/config.js` 的 `endpoint` / `publishableKey`） |

正式发布前只剩两步微信后台操作：

1. 小程序后台 → 开发 → 开发管理 → 开发设置 → **服务器域名** → `request 合法域名` 添加
   `https://mp-api.app.workbuddy.host`（平台域名，不需要你去备案）。
2. 补齐名称、头像、服务类目与**用户隐私保护指引**（收集手机号、身份证后 6 位、订单信息、剪贴板，
   用途分别是核对账户身份、记录兑换单、复制取货码）。

开发 / 体验阶段仍然建议在开发者工具里勾上「不校验合法域名」，省去反复等白名单生效。

> 下面第 2 节「备案域名 + CDN 回源」是**旧的自建后端方案**，仅在小程序要直连你自己的服务器、
> 或者要给 H5 / 公众号网页版配域名时才用得上。小程序本身已经不需要了。

## 2. 正式发布：必须先有备案域名

小程序正式版的 `request` 域名规则：**必须 HTTPS + 已 ICP 备案 + 不能带端口 + 不能是 IP**。

两条可行路径，选一条：

### 方案 A：腾讯云 CDN 加速（推荐，改动最小）

你现有的 `ypvps.com` 已经在用腾讯云 CDN，操作路径一致：

1. 腾讯云控制台 → CDN → 域名管理 → 添加域名
   - 加速域名：`jifen.ypvps.com`（换成你实际已备案的域名）
   - 源站类型：自有源
   - 回源地址：`jifen.qdmzctyun.dpdns.org`，端口 `443`，**回源协议 HTTPS**
   - 回源 HOST：`jifen.qdmzctyun.dpdns.org`（必须与源站一致，否则 Cloudflare 会 404）
2. 按提示到 DNSPod 加一条 CNAME（腾讯云会给目标值）
3. CDN 域名 → HTTPS 配置 → 申请免费证书 → 开启强制跳转
4. 打开 `https://jifen.ypvps.com/api/health` 确认返回 `{"status": "ok"}`
5. 改 `miniprogram/utils/config.js`：
   ```js
   apiBase: 'https://jifen.ypvps.com',
   ```
6. 微信后台 → 开发 → 开发管理 → 开发设置 → **服务器域名** → request 合法域名填 `https://jifen.ypvps.com` → 保存

### 方案 B：把域名 DNS 托管到 Cloudflare

`ypvps.com` 整个迁到 Cloudflare，然后 CNAME 到隧道 `71d37d49-38c7-4e11-9e60-425ff08fa27c.cfargotunnel.com`。
**不建议**：会动到生产站的解析，风险大于收益。除非你本来就想迁。

> 只有 `jifen` 这一条记录迁不过去——Cloudflare 隧道要求整个 zone 在 Cloudflare 里。

## 3. 小程序后台要补的配置（逐项照做）

登录 <https://mp.weixin.qq.com> → 用管理员微信扫码。

| 顺序 | 位置 | 要做什么 |
| --- | --- | --- |
| 1 | 设置 → 基本设置 | 填**小程序名称**（如「XX村积分超市」，名称唯一，需审核）、头像、简介、服务范围 |
| 2 | 设置 → 基本设置 → 服务类目 | 添加类目。积分兑换属村集体内部激励，一般选「生活服务 > 社区服务」或「政务民生 > 社区服务」，以列表里实际可选项为准（个人主体可选类目更少） |
| 3 | 设置 → 微信认证 | 主体若为企业/组织，需认证（300 元/年）；个人主体无法认证，功能受限但可发布 |
| 4 | 设置 → 服务内容声明 → **用户隐私保护指引** | 必须填，否则提交审核会被打回。填写：收集「姓名」「手机号」，用途「积分查询与兑换核销」，保存后生效 |
| 5 | 开发 → 开发管理 → 开发设置 → 服务器域名 | `request 合法域名` 填第 2 节的备案域名 |
| 6 | 管理 → 成员管理 | 把需要上传代码的人加成「开发者」 |
| 7 | 版本管理 | 上传代码（开发者工具「上传」）→ 提交审核 → 审核通过后点「发布」 |

审核常见打回原因，提前避开：

- 首页没有任何说明，像「空壳」→ 我们的首页有名称、标语、须知、商品，问题不大
- 类目与实际功能不符 → 一定要选社区服务类
- 隐私指引没填 / 与实际收集不符 → 按第 4 条填「姓名、手机号」
- 诱导分享、诱导关注 → 我们没做，别在页面里加「分享得积分」

## 4. 公众号怎么接

公众号这边**不需要改代码**，村民端 H5 本来就能在微信里打开。

### 4.1 菜单直链（最简单，推荐先做）

公众号后台 → 内容与互动 → 自定义菜单 → 添加菜单：

| 菜单名 | 类型 | 地址 |
| --- | --- | --- |
| 积分超市 | 跳转网页 | `https://jifen.qdmzctyun.dpdns.org/jifen.html` |
| 我的积分 | 跳转网页 | 同上（进页面后输入姓名+手机号） |
| 积分排行 | 跳转网页 | `https://jifen.qdmzctyun.dpdns.org/jifen.html#rank` |

> 微信内直接打开 H5 **不需要**配置任何域名，只要 HTTPS 正常。这条今天就能上线。

### 4.2 想要「静默登录 / 微信昵称」才需要的配置

只有用到 **网页授权（OAuth）或 JS-SDK（分享卡片、拍照上传）** 时，才需要：

1. 公众号后台 → 设置与开发 → 公众号设置 → 功能设置
2. **网页授权域名** 和 **JS 接口安全域名** 都要填**已备案的域名**（同第 2 节，不能用 ddns 免费域）
3. 按提示把 `MP_verify_xxxxx.txt` 放到站点根目录能访问到（这个我可以加到服务端静态路由，只要你给我文件名和内容）

要自动建菜单的话，需要**公众号自己的 AppID + AppSecret**（跟小程序不是一套）。给我这两个值，我可以用接口直接把菜单发上去，省得你手点。
